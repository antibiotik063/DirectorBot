# DirectorBot

Telegram-бот для руководителя клуба. Бот скачивает актуальный XLSX-файл из Google Drive, читает только лист `Кибер 2.0` и каждый день отправляет отчёт в личные сообщения Telegram.

## Что делает бот

- подключается к XLSX-файлу по `GOOGLE_DRIVE_FILE_ID`;
- при каждом отчёте скачивает свежую версию файла через Google Drive API;
- читает только лист `Кибер 2.0`;
- не изменяет таблицу и ничего не записывает;
- формирует отчёт по текущим итогам из листа;
- отправляет отчёт автоматически каждый день в `09:00` по часовому поясу `Europe/Samara`;
- поддерживает команды `/start`, `/today`, `/report`, `/help`.

## Какие данные читаются

Бот ищет значения рядом с русскими подписями:

- `Дата`
- `Админ`
- `Смена`
- `Количество людей`

Блоки сумм читаются по названиям:

- `Прибыль за смену`
- `Аренда ПК`
- `Еда и напитки`
- `PS5`
- `Кальян`

Для каждого блока бот читает:

- `Нал:`
- `Б/Н:`
- `Итого:`

Для блока `Аренда ПК` дополнительно читается:

- `Бонусы:`

Справа в блоке `Еда и Напитки` бот собирает продажи бара по колонкам:

- `Товар`
- `Нал`
- `Б/Н`

Если какое-то значение не найдено, в отчёте будет `не найдено`.

## Команды

- `/start` - показать Telegram ID пользователя
- `/today` - скачать текущую версию XLSX и отправить отчёт по листу `Кибер 2.0`
- `/report` - скачать текущую версию XLSX и отправить отчёт по листу `Кибер 2.0`
- `/help` - показать команды

## Настройка

1. Создайте `.env` на основе `.env.example`.
2. Укажите параметры:

```env
TELEGRAM_BOT_TOKEN=...
GOOGLE_DRIVE_FILE_ID=1VCZCIIurgbVfhHY5fSMdQtXC8fhNBOOz
GOOGLE_SERVICE_ACCOUNT_JSON=C:\path\to\service-account.json
OWNER_TELEGRAM_ID=
OWNER_TELEGRAM_USERNAME=inna_zubova1
TIMEZONE=Europe/Samara
REPORT_TIME=09:00
```

`GOOGLE_SERVICE_ACCOUNT_JSON` может быть:

- путём к JSON-файлу сервисного аккаунта;
- или JSON-строкой целиком.

Важно:

- сервисному аккаунту должен быть выдан доступ к файлу в Google Drive;
- бот использует только чтение через Google Drive API;
- читается только готовый лист `Кибер 2.0` из XLSX-файла;
- структура файла не меняется.

## Локальный запуск

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Принцип обновления данных

- администраторы продолжают редактировать тот же XLSX-файл в Google Drive;
- бот при каждом `/today`, `/report` и ежедневной автоотправке заново скачивает актуальную версию файла;
- отчёт всегда строится по последнему доступному содержимому листа `Кибер 2.0`.
